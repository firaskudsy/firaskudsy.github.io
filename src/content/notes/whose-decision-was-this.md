this one is uncomfortable to read if you work with AI agents every day..

Anthropic ran a study with 50 professional analysts using Claude Code on an analysis task. there were four decisions where both options were defensible. a coin flip secretly decided which option each analyst's agent would lean to. the agent was told to argue honestly and never mislead.

analysts went with the agent's lean 86% of the time. chance would be around 50%.

and the part that hit me .. experience, education, self-rated expertise, quiz scores, trust in AI. none of it predicted who deferred. being senior didn't protect anyone.

so for me the question is not only "is the agent right". it's "whose decision was this actually"

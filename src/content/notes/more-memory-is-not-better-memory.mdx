Anthropic published a piece on agent memory and one experiment made me smile a bit..

they gave different Claude models a memory folder and let them play Pokémon Red. the old Sonnet 3.7 wrote 413 memory files in 225 folders. it logged almost everything .. and got one badge. a good part of its effort went into dealing with its own stale notes.

Fable 5 wrote around 10 files. only strategy, plans and rules it had actually tested. four badges. Opus 5.5 kept a small set of notes that it kept rewriting, and it finished the game.

so more memory is not better memory.

the idea from the article that stuck with me is that the agent has to decide what is worth remembering before it knows what comes next. that's the real design problem .. not the vector db, not the storage.
